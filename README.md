# \# Database-Backed CPU Scheduler with Analytics

# 

# \## Overview

# This project implements a robust CPU scheduling engine that integrates with a database backend for persistent task management and analytics. It allows for performance benchmarking across different scheduling algorithms under varying workloads.

# 

# \## Scheduler Engine

# The core scheduler implements three fundamental CPU scheduling policies:

# \* \*\*First-Come, First-Served (FCFS)\*\*

# \* \*\*Shortest Job First (SJF)\*\*

# \* \*\*Priority Scheduling\*\*

# 

# \## Benchmarks \& Scaling

# The project includes concurrency-scaling batch scripts to test the scheduler's performance and database transaction locks under heavy, concurrent task loads.
